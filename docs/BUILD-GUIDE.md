## Stack facts

- Next.js **16.4.2** App Router, Turbopack, `cacheComponents` + `partialPrefetching`, React **19.3** (`<ViewTransition>` from `react`), React Compiler on, TypeScript **6.0.3**, Tailwind **4.3** (CSS-first, tokens in `src/app/globals.css`), Drizzle + better-sqlite3.
- Global type helpers `PageProps<'/route'>`, `LayoutProps<'/route'>`, `RouteContext<'/route'>` exist (generated by `next typegen`).
- `params` / `searchParams` are Promises.

## The static-site contract (build fails if broken)

- Every public route lives under `src/app/(site)/`, whose layout exports `ensureStatic = 'navigation'`.
- **Every DB read used for rendering** goes through an async function with `'use cache'`, `cacheLife('content')` and `cacheTag(tag.site, …)` (tags in `src/lib/cache-tags.ts`; tag the collection AND `tag.product(id)` / `tag.post(id)` for detail reads). Queries live in `src/db/queries/*.ts` and import `db` from `@/db/client`.
- Never read `cookies()`, `headers()`, `searchParams`, `connection()` in `(site)`. Never call `Date.now()`, `new Date()` (without an argument), `Math.random()` or `crypto.randomUUID()` while rendering — derive "random" things from `fnv1a(slug)` (`src/lib/utils.ts`) and dates from DB fields.
- Dynamic routes: `generateStaticParams()` returns ≥ 1 complete param set from a cached query. In the page, `const { slug } = await params` at the top, fetch, `if (!x) notFound()` **before** any `<Suspense>`. No `loading.tsx` on detail routes.
- `generateMetadata` uses the same cached queries and `pageMetadata()` from `src/lib/seo.ts`.
- Client islands read `localStorage` / `location` only after hydration (effects, `useSyncExternalStore`), inside try/catch.

## Styling rules

- Tailwind utilities with the **semantic** tokens: `bg-bg bg-surface bg-raised bg-sunken bg-wood text-ink text-muted bg-accent text-on-accent bg-bubble text-success border-line border-line-strong outline-focus`, radii `rounded-bit-xs/sm/bit/lg/xl rounded-bead`, shadows `shadow-ply shadow-ply-pressed shadow-ply-lifted shadow-paper shadow-sheet inset-shadow-tray`, type `text-2xs … text-display`, spacing `px-gutter py-section`, containers `max-w-prose/narrow/page/wide`, custom utilities `ply tray ply-band ply-type mark-swash link-mark kashida grain contact-shadow paper no-scrollbar`, fonts `font-display font-body font-accent`, easing `ease-wood ease-settle …`, durations `duration-(--dur-quick)`.
- Raw palette utilities (`bg-anar`, `text-pesteh`, `bg-shab`…) only in `src/components/illustrations/**`, `src/components/ui/**`, the footer/TheEnd night scenes.
- Complex CSS (keyframes, scroll timelines, `:has()` state machines, `@starting-style`) goes in a co-located **CSS module** `Name.module.css` that uses CSS variables (no `@apply`). Modules are inlined per route.
- RTL + **logical properties only** (`ps-* pe-* ms-* me-* start-* end-* text-start border-s`). Mirror only directional icons (`rtl:-scale-x-100`).
- Motion: default CSS = the final frame. Hidden "from" states only inside `@media (prefers-reduced-motion: no-preference)` + `@supports (animation-timeline: view())` (or `@starting-style`) and `:root:not([data-motion="reduce"]):not([data-lite])`. Animate only transform/translate/rotate/scale/opacity on **HTML** elements. Shorthand `animation:` first, then `animation-timeline`. No animation libraries (motion/framer are banned on public pages).
- Persian: no `tracking-*`, no italics, no `uppercase`, no `text-justify`, no typed kashida «ـ», Persian digits in visible text via `src/lib/format.ts`; machine values in `<data value>` / `<time dateTime>`. `<bdi lang="en" dir="ltr">` for Latin islands (SKUs, English terms).
- Never put text inside meaningful SVG; illustrations are `aria-hidden` inline or `<img alt="…">`.

## Components

- Server Components by default. `'use client'` only for the islands listed in DESIGN.md §10.2; keep them tiny, pass ids and strings, not DB rows.
- Grid/embed/cart drawings are plain `<img src={illustrationUrl(key,'assembled')} width height loading="lazy" decoding="async" alt="…">`. Only the cover scene, PDP layered stage, door/room scene kit, Tati and header/dock icons are inline SVG.
- Photos/uploads: `next/image` with real width/height and exact `sizes`; `fetchPriority="high"` + `loading="eager"` only on the one LCP image (never `priority`).
- Links: `next/link`. Primary cards/CTAs `prefetch`; deep links may set `transitionTypes={['nav-forward']}`, breadcrumbs/back `['nav-back']`.

## Content honesty

No invented reviews, people, statistics, certificates, tests or live claims. Sample reviews (`isSample`) render only when `!IS_PRODUCTION_CONTENT`, always with `SampleBadge` «نمونه», and never as schema.org `Review`. ⚑ settings that are `null` hide their UI.

## Working in parallel with other agents

- **Create/edit only the files you were assigned.** Import other areas by the agreed paths; if something you need doesn't exist yet, code against the agreed name and mention it in your report.
- **Never run `next build` or `next dev`** (one shared `.next`). Check your work with `npx tsc --noEmit 2>&1 | grep -E "<your paths>"` and `npx eslint <your files>`; ignore errors in files you don't own.
- Don't edit `package.json`; if you truly need a dependency, say so in your report.
